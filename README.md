## 🚀 Projetos em destaque

### 🎲 Sorteador de Números

Aplicação web para gerar números aleatórios dentro de um intervalo definido pelo usuário. Permite escolher a quantidade, impedir repetições e visualizar os resultados com animações.

**O que pratiquei:** JavaScript, manipulação do DOM, arrays, laços de repetição, validação de formulários e responsividade.
